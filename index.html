📶 Tags NFC & bracelet

Tout passe par les tags : les fenêtres les écoutent d'elles-mêmes, tu n'as rien à ouvrir.
Déverrouiller par bracelet
À l'ouverture, l'appli attend ton tag. Secours : 3 tapes sur le titre.
🔒 Bracelet obligatoire
Contrôles surprises dans la journée. Sans lecture = appli verrouillée.
Un élément = un seul tag, un tag = un seul élément. Choisis, puis approche le tag du dos du téléphone.
Les actions cochées ne se valident qu'en approchant le bon tag.
🔒 Tes tags sont uniques à ton installation : personne ne peut les reproduire.
Un ancien bracelet ouvre encore l'appli ? C'est que ton code d'installation n'a pas changé : tout tag écrit avec lui reste valable, même oublié du registre. Réinitialiser change ce code — et là, tout ce qui traîne devient inutilisable.
Le principe
Approcher un tag posé à un endroit précis prouve physiquement que tu as fait le geste : te lever, aller au tapis, ouvrir le frigo. Au lieu de valider depuis ton canapé, tu dois t'y rendre. C'est ce qui ancre le programme dans le réel.
Le matériel
Des tags NTAG213 ou NTAG215 (quelques euros le lot) et un bracelet NFC. Pour les tenues, des tags souples à glisser ou coudre dans le col.
Les programmer
Dans Mes tags NFC, choisis l'élément, puis approche le tag du dos du téléphone. Un élément = un seul tag, un tag = un seul élément : Foxy prévient avant d'écraser un tag actif, et refuse qu'un même tag serve deux fois.
Les poser
• ⌚ bracelet — à ton poignet, en permanence : il prouve chacun de tes changes
• 🥛 biberon — sur le biberon ou près du frigo
• 🌙 coucher — sur la porte de ta chambre
• 🍭 tétine — sur sa protection : contrôles éclair, vingt secondes au compteur
• 👕 tenues — dans le col ou à la ceinture
Valider
Quand une preuve est demandée, la fenêtre écoute déjà : tu approches, c'est validé. Rien à ouvrir, rien à viser. Le mauvais tag est refusé. En mode intensif, « valider sans preuve » disparaît.
Ouvrir l'appli
Avec Déverrouiller par bracelet, l'appli reste sur un écran neutre jusqu'à ce que tu approches ton bracelet. Dans l'application Android, un tag approché lance même Habitrain fermée.
Secours indispensable : 3 tapes rapides sur le titre débloquent toujours — bracelet perdu, abîmé, téléphone sans NFC. Garde un export de sauvegarde.
Repartir de zéro
Si un ancien tag fonctionne encore, c'est que le code d'installation n'a pas changé. Repartir de zéro le remplace : tout ce qui a été écrit avant devient illisible, d'un coup. À faire après une perte, un vol, ou un doute.
⚠️ L'appli ne peut pas vérifier qu'un tag est réellement sur toi — seulement que tu peux l'approcher. Le port réel reste ton engagement. Les délais courts et les contrôles imprévus sont là pour rendre la triche pénible, pas impossible.
